# 🤖 chekify

**chekify** — це Telegram-бот на Go, який допомагає відстежувати особисті витрати. 
Просто надсилай фото чеку або скріншот електронночого чеку або текстову 
інформацію — бот сам 
розпізнає 
покупки, віднесе їх до правильних категорій і збереже для подальшого аналізу. Все просто, приватно і без зайвого клопоту 💸

---

## 📦 Можливості

- Отримання даних про витрати через Telegram
- Класифікація покупок за категоріями
- Підтримка фото чеків та текстового вводу
- Інтеграція з Monobank
- Можливість відкласти обробку транзакції
- Збереження історії у SQLite

---

## 🛠 Технології

- **Go (Golang)**
- **Telebot** — для Telegram-інтеграції
- **SQLite** — локальна база для зберігання витрат
- **GPT** — для розпізнавання і категоризації чеків
- **Monobank API** — для автоматичного отримання транзакцій
